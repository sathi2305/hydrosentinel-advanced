# 🌊 HydroSentinel Advanced

> Real-time water quality monitoring system engineered for industrial and environmental applications. Powered by multi-sensor arrays and AI predictive analytics.

### ✨ Unique Features (What makes it different)

1.  **Digital Twin River Simulator** - Live physics-based water flow simulation with particle system, predicts 72 hours ahead
2.  **AI Anomaly Radar** - Sonar-style circular radar for pipeline leak & contamination detection
3.  **HydroGPT** - AI engineer assistant for flood & quality queries
4.  **Satellite Flood Heatmap** - Zone-wise risk prediction for Madukkarai-Coimbatore network
5.  **Blockchain Water Credits** - Gamified conservation rewards

### 🧠 Tech Stack
- **Frontend:** Glassmorphism UI, Canvas API, Real-time IoT Dashboard
- **Backend:** FastAPI, SQLite, LSTM AI Models
- **AI Engine:** Physics-informed LSTM for water level + WQI analysis
- **Deployment:** Docker, Vercel, Koyeb (Permanent)
